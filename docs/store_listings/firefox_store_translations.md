## 🇩🇪 German (Deutsch - de)

**Extension Title:** Mample - Universal Notification Hub
**Short Description:** Erhalte Push-Benachrichtigungen, wenn deine langen Webaufgaben, KI-Generierungen oder Skripte fertig sind. Ohne Account!

**Detailed Description:**
```text
Mample wartet darauf, dass deine langen Prozesse im Firefox-Browser oder auf dem Computer abgeschlossen sind, und sendet eine sofortige Push-Benachrichtigung an dein Smartphone. Ob bei KI-Generierungen oder beim Kompilieren von Code – sammle ALLE Benachrichtigungen in EINER EINZIGEN APP!

Keine Accounts, E-Mails oder Passwörter erforderlich. Scanne einfach den QR-Code, um deine Geräte in Sekunden sicher zu koppeln. Mample ist zu 100 % datenschutzorientiert; es liest, speichert oder überträgt niemals persönliche Daten.

🚀 Was kannst du tun?

• KI-Generierungs-Tracker: Warte nicht, während beliebte KI-Tools lange Texte oder Bilder generieren. Mample verfolgt den Vorgang automatisch und benachrichtigt dich, wenn er abgeschlossen ist.

• Smarte Elementauswahl: Klicke auf jeder beliebigen Website (Video-Rendering, Datei-Uploads, Datenanalyse) einfach auf den Lade-Button, auf den du wartest. Mample alarmiert dich sofort, wenn er verschwindet oder sich ändert.

• Terminal (CLI) Integration: Verbinde deinen Computer mit deinem Smartphone! Füge deinen Skripten einfach "&& mample 'Fertig'" hinzu und erhalte mobile Benachrichtigungen für Code-Kompilierungen.

• Keine Registrierung: Keine E-Mails, keine Passwörter. Scanne einfach den QR-Code, um deinen Browser anonym und sicher mit deinem Telefon zu koppeln.

📱 Wie funktioniert es?
1. Lade die Mample Mobile App auf dein Smartphone herunter.
2. Scanne den QR-Code der Erweiterung, um sie sofort zu koppeln.
3. Wähle ein Element im Web aus oder füge den Mample-Befehl deinem Terminal hinzu.
4. Hol dir einen Kaffee! Mample meldet sich, sobald deine Aufgabe erledigt ist.

Weitere Informationen: https://mample.vercel.app
```
